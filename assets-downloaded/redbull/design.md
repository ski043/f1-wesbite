# Red Bull Racing

Digital working palette for the site. These are screen values, not official paint specs.

## Colors

| Role | Name | Hex |
| --- | --- | --- |
| Main | Racing blue | `#1E5BC6` |
| Accent | Red | `#DC052D` |
| Accent | Yellow | `#F7C300` |
| Canvas | Shared black | `#080808` |
| Text | Warm white | `#F4F1EC` |
| Muted | Warm gray | `#8C877F` |

Use the shared black as the page background. Blue is the team identity. Red and yellow only in small details.

## Typography

Same system as every other team.

- Display: Instrument Serif
- UI and body: Inter Tight
- Specs and numbers: Geist Mono

Sentence case. Default letter-spacing. No uppercase tracking.
